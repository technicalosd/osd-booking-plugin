# OSD Booking WordPress Plugin

WordPress plugin for the OSD Booking system.

## Development

- Plugin files are located in the `/osd-booking` directory
- Copy or symlink `/osd-booking` into `wp-content/plugins/` for local development
- Tag releases as `v1.0.0`, `v1.1.0` etc. following semantic versioning

## Deployment

- **Manual:** Copy the `osd-booking` folder to `wp-content/plugins/`
- **Zip upload:** Zip the `osd-booking` folder and upload via WordPress Admin → Plugins → Add New
